# 🏥 OPDHeal - Outpatient Department Management System

A full-stack web application for digitalizing hospital outpatient department workflows, built with **Spring Boot** backend and **React** frontend.

## 📋 Project Overview

OPDHeal is a comprehensive hospital management solution that streamlines outpatient department operations. It provides separate portals for **Patients**, **Doctors**, and **Administrative Staff** to manage appointments, medical records, prescriptions, billing, and reporting in a secure, efficient environment.

## ✨ Features

### 🎯 **Patient Portal**
- **Appointment Management**: Book, reschedule, cancel appointments with real-time slot availability
- **Digital Medical Records**: Access prescriptions, lab reports, and medical history
- **Online Payments**: Secure payment gateway integration
- **Teleconsultation**: Integrated video calling for remote consultations
- **Health Tracking**: Graphical representation of health metrics over time

### 👨‍⚕️ **Doctor Portal**
- **Appointment Dashboard**: Daily schedule with patient details
- **E-Prescription System**: Digital prescription creation with auto-send to pharmacy
- **Patient History**: Complete medical record access during consultation
- **Leave Management**: Set availability and manage time off

### 🏢 **Admin Portal**
- **User Management**: Manage patient and doctor accounts
- **Appointment Oversight**: View and manage all appointments
- **Billing & Inventory**: Integrated pharmacy management with stock alerts
- **Analytics Dashboard**: Revenue reports, patient footfall analytics
- **Hospital Resource Management**: OPD room allocation and scheduling

## 🛠️ Technology Stack

### **Backend (Spring Boot)**
- **Framework**: Spring Boot 3.x
- **Security**: Spring Security with JWT authentication
- **ORM**: Spring Data JPA
- **Database**: PostgreSQL / MySQL
- **API Documentation**: Springdoc OpenAPI (Swagger)
- **Build Tool**: Maven
- **Validation**: Bean Validation API
- **Testing**: JUnit 5, Mockito

### **Frontend (React)**
- **Framework**: React 18+
- **State Management**: Redux Toolkit / Context API
- **UI Library**: Material-UI (MUI) / Ant Design
- **HTTP Client**: Axios
- **Routing**: React Router DOM
- **Charts**: Chart.js / Recharts
- **Form Handling**: Formik with Yup validation

### **Infrastructure & Tools**
- **Version Control**: Git
- **Containerization**: Docker & Docker Compose
- **API Testing**: Postman
- **CI/CD**: Jenkins
